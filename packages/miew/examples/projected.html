Project an atom onto the canvas

This page demonstrates two ways of projecting an atom's 3D position onto the 2D canvas using viewer.projected(): a red circle, which is a plain HTML element positioned with CSS, and a green circle, which is drawn directly onto an HTML5 canvas.

Rotate the molecule so that the tracked atom (A.1.CA) moves out of the viewer's bounds. The red circle stays visible because the HTML element is not clipped by its container, while the green circle disappears because it is drawn on a canvas that clips its contents to its own width and height. Both behaviors are expected.
